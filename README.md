# AI Financial Chatbot 💬

A web-based AI-powered chatbot that answers finance-related questions using the Groq API. 
Supports general finance topics as well as custom data input — feed it your own data 
and ask questions based on it.

## Features
- Ask anything related to finance — stocks, budgeting, investments, economics, and more
- Feed custom financial data and query against it
- Fast responses powered by Groq API (under 10 seconds)
- Clean, simple web interface

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js
- **AI:** Groq API (LLM Integration)

## Getting Started

### Prerequisites
- Node.js installed
- Groq API key

### Installation
```bash
git clone (https://github.com/sybhajantri2005-del/Wealthwhizy.git)
cd sybhajantri2005-del
npm install
```
